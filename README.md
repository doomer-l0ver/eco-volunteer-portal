# Portal for an Ecological Volunteer Movement

Responsive landing page for a non-profit community that coordinates volunteer clean-ups,
publishes waste collection points and registers participants.

## Structure
- `index.html`: semantic HTML5 markup (header, nav, main, section, article, footer)
- `style.css`: mobile-first CSS3 (Grid, Flexbox, rem/%/vh units, `@media (min-width: 1024px)`)
- `images/`: SVG icons and an optimized WebP hero image

## Features
- Adaptive navigation with a CSS-only burger menu on smartphones
- Hero section, collection points grid (1 column on mobile, 3 on desktop)
- Volunteer form with native validation (`required`, `type="email"`, `type="tel"`) and CSS validation states
- Light / Dark mode (system preference, inverted by the footer switch)

Collection point addresses are sample data for the demo.
